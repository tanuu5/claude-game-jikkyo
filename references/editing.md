# 編集台本（edit.json）と演出

## 形

フレーム番号は録画（`play.mp4`）のコマ番号（60fps）。秒（`dur` など）は出来上がりの動画の秒。

```json
{
  "voice": { "speaker": 8, "speed": 1.12 },
  "caption_y": 872, "caption_max": 26, "badge": [960, 165],
  "game_audio": { "gain": 2.2, "duck": 0.35, "fast": 0 },
  "credits": ["VOICEVOX:春日部つむぎ", "ゲーム：<タイトル>（<作者>）"],
  "cuts": [
    { "from": 9750, "to": 9990 },
    { "from": 0, "to": 240 },
    { "from": 240, "to": 1008, "speed": 4 },
    { "from": 11490, "to": 11640, "speed": 0.5, "label": "REPLAY" }
  ],
  "lines": [ { "at": 9752, "cut": 0, "text": "ちょっと待って、これ深くない？" } ],
  "fx": [
    { "at": 9760, "cut": 19, "type": "zoom", "scale": 1.5, "center": [960, 600], "dur": 1.8 },
    { "at": 9760, "cut": 19, "type": "lines", "dur": 1.6 },
    { "at": 11500, "type": "shake", "dur": 0.6, "amp": 18 },
    { "at": 9760, "type": "telop", "text": "水深1.2m！", "style": "impact", "pos": "top", "dur": 1.8 },
    { "at": 7080, "type": "sfx", "kind": "boing" }
  ]
}
```

- `src`：別の run（前回の回など）の録画とゲーム音からカットを取る。`{ "src": "last-courier", "from": 9750, "to": 9870 }`。そのカットに付けるセリフ・演出にも同じ `src` を書く（`src` のないカットとは別に数える）。
- `cuts` は並べた順に再生される。同じ範囲を 2 回使える（冒頭の予告、リプレイ）。そのコマ番号を `lines` / `fx` で指すときは `cut`（カットの番号、0 始まり）で、どの出番かを指定する。指定しないと最初に出てくるカットになる。
- `speed`：2〜6 で早送り（「▶▶ ×4」の表示が自動で出る。ゲーム音は `fast` 倍、既定 0＝無音）、0.5 でスロー。
- `lines[].delay`：秒でずらす。`voice` は行ごとにも上書きできる。
- `fx` の種類：`zoom`（`ease:"punch"` 既定＝0.12 秒で寄ってすぐ戻る、`"slow"`＝ゆっくり寄って戻る）、`lines`（集中線、`color: white|black`）、`shake`、`telop`（`style: impact|good|calm|side`、`pos: top|low|中央|[x,y]`）、`sfx`（`pop don whoosh kira ding boing`）。zoom と telop には効果音が自動で付く（`"sfx": false` で消す）。
- `caption_y`：字幕の帯の中心の高さ。ゲームの HUD（バランス計、会話ウィンドウ）と重ならない高さにする。`caption_max`：1 枚の文字数。
- `credits`：最後の 6 秒、右上に小さく出す。

## 台本の書き方

- **声の長さ**は約 6.8 文字/秒。`--check` の表の「次まで」が「長さ＋0.15 秒」より短いと重なり（✗）。✗ の行には「入るのは約 N 字」が出る。
- 1 本のセリフは 1 つのことだけ。状況説明 → 反応 → 次の行動、を短く刻む。
- 実況の型：最初に何をするゲームかを一言、依頼・目的を一言、あとは見ているものへの反応。考えたこと（メモ）はそのまま使わず、話し言葉に直して削る。
- 事実（評価、時間、数）は画面とメモで確かめた値だけを言う。言い過ぎない（「1 分近く早い」は 52 秒差で使った）。
- ゲーム内の会話や通信と重ねない。重なるならセリフを前後にずらすか、ゲーム側の文を読ませる間を空ける。

## YouTuber 風の演出の使いどころ

- **前回のあらすじ（続き物）**：前回の山場を 2 秒ずつ 3 カット（`src` で前回の録画から）、side テロップ「前回のあらすじ」と一言。そのあと作品のタイトル画面に「#2 ○○」の札。
- **おまけ**：本編を締めたあとに、ゲーム内の読み物（アーカイブ、図鑑、日誌）を読む短い場面を付ける。本編のセーブから `--restore` で別の run として撮り、`src` で末尾につなぐ。読み物は拡大（`ease:"slow"`）で文字が読める大きさにし、全文は読まずに要点と一言の感想にする。最後の一言を本編の出来事に結びつけると締まる（例：発電所の最後の記録「いつか誰かが火をつけに来る」→「今日つけに来たのが R-07」）。
- **今回の企画**：依頼文などから見どころが予想できるときは、早めに「今回の企画：○○」の札を出して、山場で回収する。
- **冒頭の予告（コールドオープン）**：いちばんの山場を 3〜4 秒、「※いきなり○○です」の side テロップと一言で先に見せる。
- **早送り**：移動・迷走・待ち時間は ×3〜×6。迷走は「迷走中…」の side テロップで笑いに変える。
- **パンチイン＋集中線＋impact テロップ＋（揺れ）**：危機の瞬間（深い、傾いた、見つかった）。1 本に 2〜3 回まで。多いと効かない。
- **リプレイ**：危機をスロー（×0.5）でもう一度。ゆっくり寄る zoom と「もう一回見てみましょう」。
- **good テロップ＋kira**：成功（渡れた、評価 A）。
- **side テロップ（黄色い札）**：ツッコミ（※フラグ、※青ではない、名前かぶり）。画面の右上寄りに置くと HUD とぶつかりにくい。
- **boing**：失敗・迷子の小ネタ。
- テロップはゲームのタイトルや HUD と重ねない（作品自身のタイトル画面にタイトルのテロップを重ねたら二重になった）。
- ゆっくり寄る zoom は情報を見せたいとき（依頼画面、スキャン結果、評価）。

## 確かめ方

```bash
node capture/build.mjs <game> --preview
for t in 1.5 17 63 97.6 115.4 136; do ffmpeg -loglevel error -y -ss $t -i runs/<game>/out/<game>_jikkyo_preview.mp4 -frames:v 1 /tmp/s_$t.jpg; done
# hstack / vstack で 1 枚にまとめて見る
```

音：`ffmpeg -i out.mp4 -af ebur128=peak=true -f null -` で I（-16 LUFS）と Peak。セリフの区間とゲーム音だけの区間の RMS を比べ、声が埋もれていないか見る。
